### สิ่งที่ทำให้เฉลยของวิชานี้ต่างจากเฉลยทั่วไป

ข้อ**ทฤษฎี**ทุกข้อบอกครบสามส่วน คือ **แนวคิดที่ใช้ตอบ** · **เหตุผลรายตัวเลือกทั้งสี่ข้อ**
(ว่าถูกเพราะอะไร หรือผิดเพราะเข้าใจอะไรคลาดเคลื่อน) · และ **สิ่งที่ต้องจำไปใช้ต่อ**

ข้อ**คำนวณ**ทุกข้อแสดงวิธีทำ 7 ขั้น และในขั้นวิเคราะห์โจทย์จะระบุ **“กับดักของข้อนี้”** ไว้ตรง ๆ
ซึ่งเก็บมาจากจุดที่นักเรียนพลาดบ่อยที่สุดจริง ๆ เช่น

- เอากำลังขยายของเลนส์สองอันมา**บวก**กันแทนที่จะ**คูณ**
- หาขนาดจริงแล้ว**คูณ**กำลังขยายแทนที่จะ**หาร**
- นับจำนวนพันธะเพปไทด์เท่ากับจำนวนกรดอะมิโน ทั้งที่ต้อง**ลบหนึ่ง**
- ลืมหักมวลน้ำที่ปล่อยออกตอนคำนวณมวลโมเลกุลของไดแซ็กคาไรด์
- เห็นคำว่า “ใช้โปรตีนช่วย” แล้วรีบตอบว่าเป็นการลำเลียงแบบใช้พลังงาน
- คิดว่าเปลี่ยนเป็นกำลังขยายสูงแล้วจะเห็นเซลล์**มากขึ้น**

### เมื่อแก้โปรแกรมแล้วต้องขึ้นเว็บใหม่

แก้ที่ **`bio.html`** เสมอ แล้วสั่งคำสั่งเดียวจากรากของรีโพ

```bash
bash tools/publish.sh "แก้อะไรไว้ เขียนสั้น ๆ ตรงนี้"
```

สคริปต์จะสร้าง `index.html` ใหม่ให้ ตรวจไวยากรณ์ทุกไฟล์ แล้ว push ขึ้นเว็บให้เอง
ถ้าขั้นไหนไม่ผ่านจะหยุดทันที ไม่ปล่อยของเสียขึ้นเว็บ

## ตรวจคลังโจทย์

เปิด `bio.html?selftest=1` จะวนสร้างทุกแม่แบบ 200 ชุดตัวเลข แล้วตรวจว่าโจทย์ เฉลย
ตัวเลือก และวิธีทำไม่มีอะไรพัง — **ต้องได้ 0 ข้อผิดพลาดก่อนขึ้นเว็บเสมอ**

## เฟสถัดไป

ภาคเรียนที่ 2 (ชีววิทยา เล่ม 2) ยังไม่ได้ทำ เมื่อจะเพิ่มให้ทำตามนี้

1. เติมบทใหม่ในอาเรย์ `TOPICS` โดยใช้ `grade: 5` เพื่อให้ไปอยู่กลุ่ม **ม.4 เทอม 2**
   แถบเลือกภาคเรียนจะโผล่ขึ้นมาเองเมื่อมีเรื่องของเทอม 2 อยู่จริง
2. เขียนแม่แบบของบทนั้นต่อท้ายคลัง โดยใช้ `topic` เป็น id ของบทใหม่
3. เติมหลักการประจำบทใน `FORMULAS` โดยใช้ id เดียวกันเป็นคีย์
4. รัน `bio.html?selftest=1` ให้ได้ 0 ข้อผิดพลาด แล้วจึง `bash tools/publish.sh`
