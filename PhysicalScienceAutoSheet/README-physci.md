### สิ่งที่ทำให้เฉลยของวิชานี้ต่างจากเฉลยทั่วไป

- **ทุกข้อคำนวณมีหัวข้อ "กับดักของข้อนี้"** ซึ่งมาจากจุดที่นักเรียนพลาดจริง เช่น
  เอาความถี่บวกความยาวคลื่นแทนที่จะคูณ · ลืมหารสองในโจทย์เสียงสะท้อน ·
  เอาเดซิเบลมาลบกันแล้วตอบว่าต่างกันกี่เท่า · เอา c คูณ n แทนที่จะหาร
- **โจทย์ทฤษฎีบอกด้วยว่าตัวเลือกอื่นผิดตรงไหน** ไม่ใช่แค่เฉลยข้อถูก
- **รูปประกอบสร้างจากตัวเลขในโจทย์จริง** ตัวเลขเปลี่ยน รูปเปลี่ยนตาม
  วิชานี้มีรูปคลื่นพร้อมป้ายความยาวคลื่นและแอมพลิจูด · รูปการหักเหพร้อมมุมและแนวฉาก ·
  วงกลมผสมแสงสี · และปริซึมกระจายแสงขาว
- **วิธีทำแสดงครบ 7 ขั้น** ทุกข้อ ตั้งแต่วิเคราะห์โจทย์จนถึงตรวจคำตอบ

## เฟสถัดไป

ยังเหลือบทที่เป็นเนื้อหาส่วนหลังของเล่ม 2 ซึ่งยังไม่ได้ทำ เช่น **คลื่นแม่เหล็กไฟฟ้า**
และ **กัมมันตภาพรังสี** วิธีเพิ่มบทใหม่

1. เติมหนึ่งบรรทัดใน `TOPICS` ที่หัวไฟล์ `physci.html` เช่น
   `{ id: 4, ch: 4, icon: '📡', name: 'คลื่นแม่เหล็กไฟฟ้า', short: 'คลื่น EM' }`
   **id ต้องไม่ซ้ำของเดิม และห้ามเปลี่ยน id เดิม** เพราะชุดโจทย์เก่าอ้างถึงอยู่
2. เพิ่มแม่แบบในส่วน "คลังแม่แบบโจทย์" ให้ครบทั้ง 4 ระดับ **ระดับละอย่างน้อย 3 แม่แบบ**
   ไม่งั้น selftest จะฟ้อง เพราะโจทย์จะซ้ำเร็วเกินไป
3. เติมหลักการของบทนั้นใน `FORMULAS` โดยใช้ id เดียวกันเป็นคีย์
4. เปิด `physci.html?selftest=1` ให้ได้ 0 ข้อผิดพลาด แล้วจึงขึ้นเว็บ

ที่เหลือทั้งระบบ — หน้าเลือกเรื่อง สถิติ การวิเคราะห์ผู้เรียน และเอกสารที่พิมพ์ —
อ่านจาก `TOPICS` กับคลังแม่แบบเองทั้งหมด ไม่ต้องแก้ที่อื่นอีก
