# PhysicsAndMath

คลังโจทย์ **ฟิสิกส์ ม.4** และ **คณิตศาสตร์ ม.ต้น** ของโรงเรียนปากช่อง จังหวัดนครราชสีมา
พัฒนาโดย **นายรังสรรค์ กรีกูล**

แต่ละวิชาเป็น **ไฟล์ HTML ไฟล์เดียวจบ** เปิดด้วยเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร
ไม่ต้องใช้เซิร์ฟเวอร์ และทำงานได้แม้ไม่มีอินเทอร์เน็ต

## 🔗 ลิงก์เดียวที่ต้องบอกนักเรียน

### https://boydzii.github.io/PhysicsAndMath/

บอกหน้าห้องครั้งเดียว ไม่ต้องแจกไฟล์ ไม่ต้องสอนทีละคน
นักเรียนเปิดลิงก์ → **ลงชื่อเข้าใช้ครั้งเดียว** → **เลือกวิชา** → ทำโจทย์ได้เลย
ไม่ต้องลงชื่อซ้ำตอนสลับวิชา

แนะนำให้นักเรียนกด **แชร์ → เพิ่มไปยังหน้าจอโฮม** ตั้งแต่ครั้งแรก
จะได้ไอคอนเหมือนแอปจริง และครั้งต่อไปไม่ต้องต่อเน็ตก็ทำโจทย์ได้

| ใคร | ใช้อะไรเข้า | ได้ไฟล์ฉบับไหน |
|---|---|---|
| **นักเรียน** | เลขประจำตัว + รหัสผ่าน (ชุดเดียวกับที่ใช้ในแอพฟิสิกส์) | ไม่มีเฉลย ไม่มีสถิติชั้นเรียน |
| **ครู** | อีเมล + รหัสผ่านผู้ดูแล | ฉบับเต็ม เห็นเฉลยและสถิติทั้งหมด |

## ทำอะไรได้บ้าง

- **สุ่มโจทย์ไม่ซ้ำ** — เก็บแค่ชื่อแม่แบบกับเลขสุ่ม (seed) จึงสร้างชุดเดิมกลับมาได้เป๊ะทุกตัวเลขเสมอ
- **ตรวจคำตอบทันที** พร้อม **วิธีทำละเอียด 7 ขั้น** ทุกข้อ และหัวข้อ *"กับดักของข้อนี้"*
- **โจทย์ทฤษฎีบอกด้วยว่าตัวเลือกอื่นผิดตรงไหน** ไม่ใช่แค่เฉลยข้อถูก
- **รูปประกอบสร้างจากตัวเลขในโจทย์จริง** ตัวเลขเปลี่ยน รูปเปลี่ยนตาม
- **วิเคราะห์ผู้เรียน 4 มุม** — ตามเรื่อง / ระดับความยาก / หัวข้อย่อย / ทักษะ
- **สถิติชั้นเรียน** ค่าเฉลี่ย SD การกระจายคะแนน และวิเคราะห์รายข้อ (ค่า p และ r)
- **พิมพ์ 4 แบบ** — ใบงาน · ใบเฉลย · หลักฐานการเรียนรู้ · รายงานสถิติชั้นเรียน

## หน้าพอร์ทัลทำงานอย่างไร

`index.html` ที่หน้าแรกเป็นหน้าลงชื่อเข้าใช้ + เลือกวิชา

1. ส่งเลขประจำตัวกับรหัสผ่านไปให้ **Google Apps Script ของชีตเป็นคนตรวจ**
   ซึ่งเป็นการตรวจของจริง ปลอมฝั่งเบราว์เซอร์ไม่ได้
2. ได้โทเคนกลับมาแล้วเก็บไว้ที่ `localStorage` คีย์ `pcportal.v1`
3. แอพทั้งสองวิชาอยู่โดเมนเดียวกัน จึงอ่านโทเคนก้อนนั้นต่อได้เลย
   (`adoptPortalSession()` ในแอพฟิสิกส์ · `adoptPortalProfile()` ในแอพคณิต)
   นักเรียนจึงลงชื่อครั้งเดียวใช้ได้ทุกวิชา และแอพคณิตยังได้ชื่อกับเลขที่มาเติมให้อัตโนมัติ
4. โทเคนหมดอายุใน 11.5 ชั่วโมง หรือกด **ออกจากระบบ** ที่หน้าพอร์ทัล

**อีเมลของครูเก็บเป็นค่าแฮช SHA-256** ไม่ใช่อีเมลตรง ๆ จะได้ไม่ถูกบอตกวาดไปจากหน้าเว็บ
เปลี่ยนอีเมล: เปิดหน้าพอร์ทัล กด F12 พิมพ์ `hashEmail('อีเมลใหม่')` แล้วเอาค่าที่ได้ไปวางแทน
`TEACHER_EMAIL_HASH` ใน `index.html`

### ข้อจำกัดที่ต้องรู้ ⚠️

GitHub Pages เป็น**เว็บนิ่ง ไม่มีเซิร์ฟเวอร์** หน้าพอร์ทัลจึงเป็น **ประตูทางเข้าที่สะดวก
ไม่ใช่กำแพงกันคนเข้า** — ใครพิมพ์ที่อยู่ของไฟล์แอพตรง ๆ ก็เปิดได้ และรหัสที่ตรวจฝั่งเบราว์เซอร์
(การเทียบอีเมล) อ่านได้จากซอร์ส

**ของจริงที่กันได้อยู่ที่ชีต** — ไม่มีโทเคนที่ชีตออกให้ ก็ดึงใบงานที่ครูมอบหมายไม่ได้
ส่งผลขึ้นชีตไม่ได้ และดูรายชื่อหรือคะแนนของคนอื่นไม่ได้

เนื่องจากรีโพนี้เป็นสาธารณะ **ที่อยู่ Apps Script จึงเปิดเผยไปด้วย** ควร

- ตั้ง**รหัสผู้ดูแลให้ยาวและเดายาก** เพราะเป็นด่านเดียวที่กันคนนอกออกจากส่วนของครู
- เปลี่ยนรหัสนักเรียนตั้งต้นให้ไม่ซ้ำกันทุกคน
- ถ้าวันไหนอยากตัดขาด ให้ **Deploy ใหม่ใน Apps Script** แล้วที่อยู่เดิมจะใช้ไม่ได้ทันที
  จากนั้นแก้ที่อยู่ใหม่ใน `index.html` กับ `tools/build-dist.mjs`

## เวลาแก้โปรแกรมแล้วอัปขึ้นเว็บ

แก้ที่ **ไฟล์ต้นฉบับ** เสมอ (`physics.html` / `math.html`) แล้วสร้างไฟล์ฉบับขึ้นเว็บใหม่

```bash
node tools/build-dist.mjs
```

สคริปต์จะเขียนบล็อก `@@BUILTIN@@` ทับให้ตามที่ตั้งไว้ เนื้อโปรแกรมที่เหลือเหมือนกันทุกตัวอักษร
สองไฟล์จึงไม่มีทางหลุดจากกัน จากนั้น `git push` แล้ว GitHub Pages จะอัปเดตเองภายในไม่กี่นาที

> ในแอพยังมีปุ่ม **ตั้งค่า → สร้างไฟล์สำหรับแจกนักเรียน** อยู่เหมือนเดิม
> ปุ่มนั้นฝังตราโรงเรียนและหัวกระดาษที่ตั้งไว้ลงไปด้วย เหมาะกับตอนแจกไฟล์เดี่ยว ๆ ทางไลน์

## ตรวจคลังโจทย์

เปิดไฟล์ต่อท้ายด้วย `?selftest=1` เช่น `math.html?selftest=1`
จะวนสร้างทุกแม่แบบ 200 ชุดตัวเลข แล้วตรวจว่าโจทย์ เฉลย และตัวเลือกไม่มีอะไรพัง

ไฟล์ตรวจงานเพิ่มเติมอยู่ใน `outputs/` — หน้ารวมรูปประกอบ และตัวอย่างโจทย์พร้อมเฉลยทุกแม่แบบ

## หมายเหตุเรื่องข้อมูลส่วนตัว

`.gitignore` ของรีโพนี้ใช้วิธี **ปิดทุกอย่างก่อนแล้วเปิดเฉพาะไฟล์ที่ตั้งใจ**
เพราะโฟลเดอร์ทำงานจริงมีรายชื่อนักเรียน ตารางสอน อีเมลและเบอร์โทรครู
และไฟล์สำรองคะแนนปนอยู่ด้วย

**จะเพิ่มไฟล์ใหม่เข้ารีโพ ต้องไปเติมบรรทัด `!` ใน `.gitignore` เท่านั้น**
ไม่งั้นไฟล์จะไม่ถูกนับ — ตั้งใจให้เป็นแบบนี้เพื่อกันข้อมูลนักเรียนหลุดโดยไม่ตั้งใจ
