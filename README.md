คลังโจทย์ **คณิตศาสตร์ ม.ต้น** · **วิทยาศาสตร์ ม.ต้น** · **ฟิสิกส์ ม.4** · **เคมี ม.4**
**ชีววิทยา ม.4** และ **วิทยาศาสตร์กายภาพ ม.5**
พร้อม **ห้องเรียนสมดุลกล** — แอปการเรียนรู้แบบมีซิมมูเลชันและเก็บคะแนนขึ้น Google Sheet
ของโรงเรียนปากช่อง จังหวัดนครราชสีมา
พัฒนาโดย **นายรังสรรค์ กรีกูล**

แต่ละวิชาเป็น **ไฟล์ HTML ไฟล์เดียวจบ** เปิดด้วยเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไร

ไม่ต้องลงชื่อซ้ำตอนสลับวิชา

|---|---|---|
| **นักเรียน** | เลขประจำตัว + รหัสผ่าน (ชุดเดียวกับที่ใช้ในแอพฟิสิกส์) | ไม่มีเฉลย ไม่มีสถิติชั้นเรียน |
| **ครู** | อีเมล + รหัสผ่านผู้ดูแล | ฉบับเต็ม เห็นเฉลยและสถิติทั้งหมด |

หกแอพข้างบนเป็น **คลังโจทย์** — เข้ามาเพื่อสุ่มโจทย์ ทำ แล้วพิมพ์ใบงาน
ส่วนแอพนี้เป็น **แอปการเรียนรู้เต็มรูปแบบของเรื่องเดียว** — เรียน → ทดลอง → ฝึก → วัดผล
มีบทเรียนให้อ่าน มีซิมมูเลชันให้ลากเล่นจริง มีระบบ XP เหรียญตรา และสถิติต่อเนื่องรายวัน
เจาะเรื่อง **สมดุลกล** ซึ่งเป็นบทที่นักเรียนพลาดกันมากที่สุดบทหนึ่ง

นักเรียนเข้าด้วย **รหัสเข้าเรียน 4 ตัวอักษร** ที่ครูสร้างและพิมพ์แจกได้จากในแอป
(ตัดเลข 0 กับ 1 และตัว I กับ O ออก เพราะเป็นคู่ที่อ่านสลับกันบ่อยที่สุด)

การ์ดของแอปนี้จะขึ้นในหน้าพอร์ทัล **เฉพาะตอนที่ครูลงชื่อเข้าใช้ในฐานะผู้ดูแล**
นักเรียนไม่เห็น และชื่อไม่ไปโผล่ในบรรทัดรายชื่อวิชาใต้หัวเรื่อง

รูปที่วาดส่งออกเป็นโค้ด SVG วางลงช่อง `figure` ของแม่แบบโจทย์ได้ทันที
สีในรูปผูกกับ**ตัวแปรธีม** ไม่ได้ฝังรหัสสี รูปจึงอ่านออกทั้งโหมดสว่างและโหมดมืด
และไม่ได้ตั้งชื่อคลาสใหม่ จึงไม่ชนกับคลาสของหน้าเว็บ

คลังรูปเก็บอยู่ใน **เบราว์เซอร์เครื่องนั้นเท่านั้น** — ควรกด *ส่งออกทั้งคลัง* เก็บไฟล์ไว้เป็นระยะ
ไม่งั้นล้างข้อมูลเว็บทีเดียวคลังหายหมด

## ทำอะไรได้บ้าง

- **สุ่มโจทย์ไม่ซ้ำ** — เก็บแค่ชื่อแม่แบบกับเลขสุ่ม (seed) จึงสร้างชุดเดิมกลับมาได้เป๊ะทุกตัวเลขเสมอ
- **ตรวจคำตอบทันที** พร้อม **วิธีทำละเอียด 7 ขั้น** ทุกข้อ และหัวข้อ *"กับดักของข้อนี้"*
- **โจทย์ทฤษฎีบอกด้วยว่าตัวเลือกอื่นผิดตรงไหน** ไม่ใช่แค่เฉลยข้อถูก
- **รูปประกอบสร้างจากตัวเลขในโจทย์จริง** ตัวเลขเปลี่ยน รูปเปลี่ยนตาม
- **วิเคราะห์ผู้เรียน 4 มุม** — ตามเรื่อง / ระดับความยาก / หัวข้อย่อย / ทักษะ
- **สถิติชั้นเรียน** ค่าเฉลี่ย SD การกระจายคะแนน และวิเคราะห์รายข้อ (ค่า p และ r)
- **พิมพ์ 4 แบบ** — ใบงาน · ใบเฉลย · หลักฐานการเรียนรู้ · รายงานสถิติชั้นเรียน
- **ใบงานจัดหน้าจากความสูงจริงของแต่ละข้อ** เลือกความหนาแน่นได้ 3 ระดับ
  ตั้งแต่โปร่ง (แสดงวิธีทำ 1 ข้อ/หน้า) ถึงแน่น (ปรนัย 3–5 ข้อ/หน้า · แสดงวิธีทำ 3 ข้อ/หน้า)

## หน้าพอร์ทัลทำงานอย่างไร

`index.html` ที่หน้าแรกเป็นหน้าลงชื่อเข้าใช้ + เลือกวิชา

1. ส่งเลขประจำตัวกับรหัสผ่านไปให้ **Google Apps Script ของชีตเป็นคนตรวจ**
   ซึ่งเป็นการตรวจของจริง ปลอมฝั่งเบราว์เซอร์ไม่ได้
2. ได้โทเคนกลับมาแล้วเก็บไว้ที่ `localStorage` คีย์ `pcportal.v1`
3. แอพทุกวิชาอยู่โดเมนเดียวกัน จึงอ่านโทเคนก้อนนั้นต่อได้เลยด้วย `adoptPortalSession()`
   นักเรียนจึงลงชื่อครั้งเดียวใช้ได้ทุกวิชา และได้ชื่อ ชั้น เลขที่ มาเติมให้อัตโนมัติ

**เพิ่มวิชาใหม่แก้ที่เดียว** — เติมหนึ่งบล็อกในอาเรย์ `SUBJECTS` ใน `index.html`
แล้วการ์ดเลือกวิชา ปุ่มเข้าแบบไม่ต้องลงชื่อ และบรรทัดชื่อวิชาใต้หัวเรื่อง จะขึ้นเองทั้งหมด
ถ้าวิชานั้นยังทำไม่เสร็จ ใส่ `soon: 'กำลังจัดทำ'` ไว้ก่อน การ์ดจะขึ้นให้เห็นแต่ยังกดเข้าไม่ได้
4. โทเคนหมดอายุใน 11.5 ชั่วโมง หรือกด **ออกจากระบบ** ที่หน้าพอร์ทัล

**อีเมลของครูเก็บเป็นค่าแฮช SHA-256** ไม่ใช่อีเมลตรง ๆ จะได้ไม่ถูกบอตกวาดไปจากหน้าเว็บ
เปลี่ยนอีเมล: เปิดหน้าพอร์ทัล กด F12 พิมพ์ `hashEmail('อีเมลใหม่')` แล้วเอาค่าที่ได้ไปวางแทน
`TEACHER_EMAIL_HASH` ใน `index.html`

### ข้อจำกัดที่ต้องรู้ ⚠️

GitHub Pages เป็น**เว็บนิ่ง ไม่มีเซิร์ฟเวอร์** หน้าพอร์ทัลจึงเป็น **ประตูทางเข้าที่สะดวก
ไม่ใช่กำแพงกันคนเข้า** — ใครพิมพ์ที่อยู่ของไฟล์แอพตรง ๆ ก็เปิดได้ และรหัสที่ตรวจฝั่งเบราว์เซอร์
(การเทียบอีเมล) อ่านได้จากซอร์ส

**ของจริงที่กันได้อยู่ที่ชีต** — ไม่มีโทเคนที่ชีตออกให้ ก็ดึงใบงานที่ครูมอบหมายไม่ได้
ส่งผลขึ้นชีตไม่ได้ และดูรายชื่อหรือคะแนนของคนอื่นไม่ได้

เนื่องจากรีโพนี้เป็นสาธารณะ **ที่อยู่ Apps Script จึงเปิดเผยไปด้วย** ควร

- ตั้ง**รหัสผู้ดูแลให้ยาวและเดายาก** เพราะเป็นด่านเดียวที่กันคนนอกออกจากส่วนของครู
- เปลี่ยนรหัสนักเรียนตั้งต้นให้ไม่ซ้ำกันทุกคน
- ถ้าวันไหนอยากตัดขาด ให้ **Deploy ใหม่ใน Apps Script** แล้วที่อยู่เดิมจะใช้ไม่ได้ทันที
  จากนั้นแก้ที่อยู่ใหม่ใน `index.html` กับ `tools/build-dist.mjs`

## เวลาแก้โปรแกรมแล้วอัปขึ้นเว็บ

แก้ที่ **ไฟล์ต้นฉบับ** เสมอ
(`math.html` / `science.html` / `physics.html` / `chem.html` / `bio.html` / `physci.html` / `equilibrium.html`)
แล้วสั่งคำสั่งเดียวจบ

```bash
bash tools/publish.sh "แก้อะไรไว้ เขียนสั้น ๆ ตรงนี้"
```

สคริปต์จะทำให้ตามลำดับ แล้วหยุดทันทีถ้าขั้นไหนไม่ผ่าน (จะได้ไม่ปล่อยของเสียขึ้นเว็บ)

1. `node tools/build-dist.mjs` — สร้างไฟล์ฉบับนักเรียนของทุกวิชาใหม่จากไฟล์ต้นฉบับ
   (ห้องวาดรูปโจทย์ไม่มีฉบับนักเรียน สคริปต์จึงไม่ยุ่งกับไฟล์นั้น)
2. `node tools/check.mjs` — ตรวจไวยากรณ์ทุกไฟล์ และตรวจว่าฉบับนักเรียนตรงกับฉบับครูเป๊ะ
3. `git commit` แล้ว `git push` ขึ้น `main` — GitHub Pages เผยแพร่ให้เองใน 1–2 นาที

จะสั่งทีละขั้นเองก็ได้ถ้าอยากดูผลระหว่างทาง

```bash
node tools/build-dist.mjs && node tools/check.mjs
```

สคริปต์สร้างไฟล์จะเขียนบล็อก `@@BUILTIN@@` ทับให้ตามที่ตั้งไว้ เนื้อโปรแกรมที่เหลือเหมือนกันทุกตัวอักษร
สองไฟล์จึงไม่มีทางหลุดจากกัน และถ้าเผลอแก้ที่ฉบับนักเรียนโดยตรง `check.mjs` จะฟ้องให้รู้ตัว

> **ห้องเรียนสมดุลกลใช้ชีตคนละใบ** กับอีกสี่วิชา ที่อยู่เว็บแอปของมันอยู่ที่ตัวแปร
> `EQ_APPS_URL` ตรงหัวไฟล์ `tools/build-dist.mjs` ถ้ายังไม่ได้ใส่ สคริปต์จะไม่ยอมสร้างไฟล์ให้
> เพราะไฟล์ที่แจกนักเรียนจะเปิดใช้ได้ตามปกติแต่คะแนนไม่ขึ้นชีต ซึ่งกว่าจะรู้ตัวก็สอบไปแล้ว

> ในแอพยังมีปุ่ม **ตั้งค่า → สร้างไฟล์สำหรับแจกนักเรียน** อยู่เหมือนเดิม
> ปุ่มนั้นฝังตราโรงเรียนและหัวกระดาษที่ตั้งไว้ลงไปด้วย เหมาะกับตอนแจกไฟล์เดี่ยว ๆ ทางไลน์

จะวนสร้างทุกแม่แบบ 200 ชุดตัวเลข แล้วตรวจว่าโจทย์ เฉลย ตัวเลือก
และตัวเลขที่โจทย์กำหนดให้ ไม่มีอะไรพัง — **ต้องได้ 0 ข้อผิดพลาดก่อนขึ้นเว็บเสมอ**

ไฟล์ตรวจงานเพิ่มเติมอยู่ใน `outputs/` — หน้ารวมรูปประกอบ และตัวอย่างโจทย์พร้อมเฉลยทุกแม่แบบ

---

## หมายเหตุเรื่องข้อมูลส่วนตัว

`.gitignore` ของรีโพนี้ใช้วิธี **ปิดทุกอย่างก่อนแล้วเปิดเฉพาะไฟล์ที่ตั้งใจ**
เพราะโฟลเดอร์ทำงานจริงมีรายชื่อนักเรียน ตารางสอน อีเมลและเบอร์โทรครู
และไฟล์สำรองคะแนนปนอยู่ด้วย

**จะเพิ่มไฟล์ใหม่เข้ารีโพ ต้องไปเติมบรรทัด `!` ใน `.gitignore` เท่านั้น**
ไม่งั้นไฟล์จะไม่ถูกนับ — ตั้งใจให้เป็นแบบนี้เพื่อกันข้อมูลนักเรียนหลุดโดยไม่ตั้งใจ
