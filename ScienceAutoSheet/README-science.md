# คลังโจทย์วิทยาศาสตร์ ม.ต้น — สุ่มโจทย์ ทำในแอพ ตรวจคำตอบ และพิมพ์ PDF

แอพนี้เป็น **ไฟล์ HTML ไฟล์เดียวจบ** เปิดด้วยเบราว์เซอร์ได้ทันที
ไม่ต้องติดตั้งอะไร ไม่ต้องใช้เซิร์ฟเวอร์ และทำงานได้แม้ไม่มีอินเทอร์เน็ต

ใช้ **เอนจินชุดเดียวกับคลังโจทย์คณิตศาสตร์และฟิสิกส์** ทั้งการสุ่มโจทย์
การแสดงวิธีทำ 7 ขั้น การวิเคราะห์ผู้เรียน และเอกสารสำหรับพิมพ์
ต่างกันที่ **คลังแม่แบบโจทย์** และ **รูปประกอบ** ซึ่งเป็นของวิชาวิทยาศาสตร์โดยเฉพาะ

## ระดับของโจทย์มี 4 ระดับ

| ระดับ | จำนวนต่อบท | รูปแบบการตอบ | เน้นอะไร |
|---|---|---|---|
| **ทฤษฎี** | 4 | ปรนัย 4 ตัวเลือก | ความเข้าใจ ไม่ต้องคำนวณ |
| **ง่าย** | 4 | ปรนัย 4 ตัวเลือก | แทนค่าลงสูตรตรง ๆ หนึ่งขั้น |
| **ปานกลาง** | 4 | กรอกคำตอบ | ต้องทำสองขั้นขึ้นไป หรือย้ายข้างสูตร |
| **ยาก** | 3 | กรอกคำตอบ | ทำงานย้อนกลับ รวมหลายเรื่อง หรือหลายช่วงข้อมูล |

### โจทย์ทฤษฎีบอกด้วยว่าตัวเลือกอื่นผิดตรงไหน

โจทย์ระดับทฤษฎีทุกข้อมีคำอธิบาย **รายตัวเลือก** ว่าถูกหรือผิดเพราะอะไร
ไม่ใช่แค่บอกว่าข้อไหนถูก จึงใช้สอนซ่อมเสริมความเข้าใจผิดได้ตรงจุด

### ทุกข้อมีหัวข้อ "กับดักของข้อนี้"

ในขั้นที่ 1 ของวิธีทำ (วิเคราะห์โจทย์) จะระบุความผิดพลาดที่นักเรียนพลาดบ่อยที่สุดของข้อนั้นไว้เสมอ
เช่น ลืมแปลงหน่วย · ใช้ฐานของร้อยละผิด · ลืมยกกำลังสอง · หารด้วยตัวเดียวทั้งที่ต้องหารสองตัว

## รูปประกอบโจทย์

รูปทั้งหมดเป็น **SVG ที่สร้างจากตัวเลขในโจทย์จริง** ตัวเลขเปลี่ยน รูปเปลี่ยนตาม
และเปลี่ยนสีตามโหมดสว่าง-มืดเองโดยอัตโนมัติ

| ฟังก์ชัน | ใช้กับ |
|---|---|
| `figXY` | กราฟอเนกประสงค์ — กราฟให้ความร้อน · กราฟ v–t · อัตราการเกิดปฏิกิริยา · ความเข้มแสง |
| `figBarChart` | แผนภูมิแท่ง เช่น ปริมาณน้ำฝนรายเดือน |
| `figBeaker` · `figFloat` | บีกเกอร์ กระบอกตวง การจมการลอย แรงพยุง |
| `figCell` · `figLeafGas` | เซลล์พืช-เซลล์สัตว์ · การสังเคราะห์ด้วยแสง |
| `figThermo` · `figHeatFlow` | เทอร์โมมิเตอร์ · การนำความร้อน |
| `figLayers` | ชั้นบรรยากาศ · ชั้นหิน · โครงสร้างโลก |
| `figSepar` | ชุดกลั่น · การกรอง · โครมาโทกราฟี |
| `figForcesPoint` · `figBeam` · `figWorkPull` | แรงลัพธ์ · คานและโมเมนต์ · งานและกำลัง |
| `figCircuit` | วงจรไฟฟ้าอนุกรมและขนาน |
| `figPH` | สเกล pH |
| `figPunnett` | ตารางพันเนตต์ |
| `figFoodChain` · `figPyramidEco` | โซ่อาหาร · พีระมิดพลังงาน |
| `figOrbit` | ข้างขึ้นข้างแรม |

> ⚠ **ชื่อคลาสในรูปต้องขึ้นต้นด้วย `f` ทุกตัว** (`fbar` `fbox` `ffil` `fgrd` `fpt`)
> เพราะเบราว์เซอร์ถือว่า `width` และ `height` ของ SVG เป็นสมบัติ CSS ด้วย
> ถ้าชื่อคลาสไปชนกับคลาสของหน้าเว็บ ความสูงของแท่งกราฟจะถูกทับจนรูปเพี้ยนทั้งรูป

## การพิมพ์ใบงาน

แท็บ **พิมพ์ / PDF** มีตัวเลือก **ความหนาแน่น** สามระดับ ซึ่งคุมสามอย่างพร้อมกัน
คือ ขนาดรูปประกอบ · ความสูงบรรทัดของกรอบเขียนวิธีทำ · และจำนวนบรรทัดในกรอบนั้น

| ระดับ | รูปประกอบ | กรอบเขียนวิธีทำ | ข้อปรนัยต่อหน้า | ข้อแสดงวิธีทำต่อหน้า |
|---|---|---|---|---|
| **โปร่ง** | กว้าง 74 มม. | มีหัวข้อครบ 5 ขั้น บรรทัดกว้าง | 2-4 ข้อ | 1 ข้อ |
| **ปานกลาง** | กว้าง 46 มม. | มีหัวข้อครบ 5 ขั้น | 3-4 ข้อ | 2 ข้อ |
| **แน่น** | กว้าง 32 มม. | ตัดหัวข้อออก เหลือบรรทัดเปล่า | 3-5 ข้อ | 3 ข้อ |

**การตัดหน้าใช้การวัดความสูงจริง** ไม่ใช่การเดา — ระบบวัดความสูงของแต่ละข้อ
ในกล่องที่ตั้งความกว้างเท่ากระดาษ A4 จริง (182 มม.) แล้วจึงตัดหน้า
แต่ละหน้าจึงเต็มพอดี ไม่เหลือที่ว่างครึ่งหน้าเหมือนตอนปล่อยให้เบราว์เซอร์ตัดเอง

> จำนวนข้อต่อหน้าจึงต่างกันได้ตามความยาวของโจทย์และขนาดรูปในหน้านั้น
> ซึ่งเป็นเรื่องปกติ และดีกว่าการบังคับจำนวนเท่ากันทุกหน้าจนเหลือที่ว่าง

ปรับจำนวนบรรทัดตั้งต้นของแต่ละช่องได้ที่แท็บ **ตั้งค่า** ส่วนความหนาแน่นจะย่อ-ขยายจากค่านั้นอีกที

## ตรวจคลังโจทย์

เปิด `science.html?selftest=1` จะวนสร้าง **ทุกแม่แบบ 200 ชุดตัวเลข** (45,000 โจทย์)
แล้วตรวจว่าโจทย์ เฉลย ตัวเลือก และตัวเลขที่โจทย์กำหนดให้ ไม่มีอะไรพัง

ตัวตรวจจะฟ้องเมื่อพบสิ่งเหล่านี้

- โจทย์หรือเฉลยมีคำว่า `undefined` `NaN` หรือช่อง `{ตัวแปร}` ที่ยังไม่ถูกแทนค่า
- ตัวเลือกปรนัยไม่ครบ 4 ตัว หรือมีข้อถูกไม่ใช่หนึ่งข้อ
- คำตอบหรือ **ค่าที่โจทย์กำหนดให้** มีทศนิยมเกิน 2 ตำแหน่ง (เลขไม่สวย)
- บทใดบทหนึ่งยังมีระดับที่ว่างอยู่

**ต้องได้ 0 ข้อผิดพลาดก่อนนำไปใช้จริงเสมอ**

## วิธีเพิ่มแม่แบบโจทย์ใหม่

1. เปิด `science.html` ไปที่ส่วน **4) คลังแม่แบบโจทย์**
2. หาบทที่ต้องการ แล้วเขียนบล็อกใหม่ต่อท้าย
   - `TQ({...})` สำหรับโจทย์ทฤษฎี (ปรนัย เน้นความเข้าใจ)
   - `T({...})` สำหรับโจทย์คำนวณ โดยระบุ `level` เป็น `'ง่าย'` `'ปานกลาง'` หรือ `'ยาก'`
3. `id` ของแม่แบบ **ห้ามซ้ำและห้ามเปลี่ยนของเดิม** เพราะชุดโจทย์เก่าอ้างถึงอยู่
4. คืน `null` จาก `gen()` ได้เสมอ เมื่อตัวเลขที่สุ่มมาไม่สวย ระบบจะสุ่มใหม่ให้เอง
5. เปิด `science.html?selftest=1` แล้วต้องได้ 0 ข้อผิดพลาด
6. สร้างไฟล์นักเรียนใหม่ด้วย `node tools/build-dist.mjs`

### วิธีเพิ่มบทใหม่

1. เติมหนึ่งบรรทัดใน `TOPICS` โดยใช้ `id` ที่เข้ารหัสระดับชั้นไว้ (1xx = ม.1 · 2xx = ม.2 · 3xx = ม.3)
2. เขียนแม่แบบให้ครบทั้ง 4 ระดับ อย่างน้อยระดับละ 3 แม่แบบ
3. เติมสูตรของบทนั้นใน `FORMULAS` โดยใช้ `id` เดียวกันเป็นคีย์
4. ที่เหลือทั้งระบบ — หน้าเลือกเรื่อง สถิติ การวิเคราะห์ และเอกสารพิมพ์ —
   อ่านจาก `TOPICS` กับ `TPL` เองทั้งหมด ไม่ต้องแก้ที่อื่นอีก

## ส่วนที่เหมือนกับคลังโจทย์คณิตศาสตร์ทุกอย่าง

เรื่องต่อไปนี้ใช้กลไกเดียวกันเป๊ะ อ่านรายละเอียดได้ที่
[README-math.md](../MathAutoSheet/README-math.md)

- การทำงานของเลขสุ่ม (seed) และการสร้างชุดโจทย์เดิมซ้ำ
- แบบฝึกหัด กับ แบบทดสอบ และการเลื่อน seed ไม่ให้ตัวเลขซ้ำกัน
- การวิเคราะห์ผู้เรียน 4 มุม (ตามเรื่อง / ระดับความยาก / หัวข้อย่อย / ทักษะ)
- สถิติชั้นเรียน ค่า p และค่า r รายข้อ
- การสำรองและกู้คืนข้อมูล
- การรับช่วงการลงชื่อเข้าใช้จากหน้าพอร์ทัล

## หมายเหตุเรื่องการรับช่วงการลงชื่อเข้าใช้

แอพนี้อ่านโทเคนจาก `localStorage` คีย์ `pcportal.v1` ที่หน้าพอร์ทัลเขียนไว้
นักเรียนจึงลงชื่อครั้งเดียวแล้วใช้ได้ทุกวิชา และได้ชื่อ ชั้น เลขที่ มาเติมให้อัตโนมัติ

ข้อมูลของแอพนี้เก็บแยกจากวิชาอื่นที่คีย์ `sciquiz.v1`
(คณิตใช้ `mathquiz.v1` · ฟิสิกส์ใช้คีย์ของตัวเอง) จึงเปิดหลายวิชาพร้อมกันได้โดยไม่กวนกัน
