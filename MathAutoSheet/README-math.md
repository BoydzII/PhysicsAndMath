### โจทย์ทฤษฎี — เฉลยบอกด้วยว่าตัวเลือกอื่นผิดตรงไหน

ข้อทฤษฎีทุกข้อมีคำอธิบาย 3 ส่วน คือ **แนวคิดที่ใช้ตอบ** · **เหตุผลรายตัวเลือกทั้ง 4 ข้อ**
(ว่าถูกเพราะอะไร หรือผิดเพราะเข้าใจอะไรคลาดเคลื่อน) · และ **สิ่งที่ต้องจำไปใช้ต่อ**

จึงใช้ปิดช่องว่างความเข้าใจผิดที่ฝังลึกได้ตรงจุด เช่น
*"ตัวส่วนมากแปลว่าเศษส่วนมีค่ามาก"* · *"ลด 20% แล้วลดอีก 10% เท่ากับลด 30%"* ·
*"ความสูงของสามเหลี่ยมคือด้านที่เอียง"*

## การตอบคำถาม — คณิตต่างจากฟิสิกส์ตรงนี้

โจทย์คณิตไม่ได้ตอบเป็นทศนิยมเสมอไป แอพจึงรองรับคำตอบ 4 แบบ และบอกกติกาไว้เหนือช่องกรอกทุกข้อ

| ชนิดคำตอบ | นักเรียนพิมพ์ได้แบบไหน | การตรวจ |
|---|---|---|
| **จำนวนเต็ม** | `-8` · `1,200` | ต้องตรงเป๊ะ ไม่มีการปัดเศษ |
| **ทศนิยม** | `2.5` · `2.5x10^3` | ยอมคลาดเคลื่อนตามที่ตั้งไว้ (เริ่มต้น 1%) |
| **เศษส่วน** | `3/4` · `-2/5` · `1 1/2` | เทียบด้วยค่า |
| **เศษส่วนอย่างต่ำ** | `3/4` (ไม่รับ `6/8`) | ต้องย่ออย่างต่ำมาแล้วจริง |

- โจทย์ที่บังคับ **"ตอบเป็นเศษส่วนอย่างต่ำ"** จะเขียนไว้ในตัวโจทย์ และแอพจะไม่รับคำตอบที่ยังไม่ย่อ
- โจทย์ที่ถาม 2 ค่า เช่น หาจำนวนถุงและจำนวนของต่อถุง จะมี 2 ช่อง **ถูกช่องละครึ่งคะแนน**
- **คะแนนล็อกที่การตรวจครั้งแรก** กด *ลองทำใหม่* ได้เพื่อฝึก แต่ไม่นับคะแนนเพิ่ม
- แถบตัวเลขข้อด้านบนบอกสถานะทุกข้อ เขียว = ถูก · เหลือง = ถูกบางส่วน · แดง = ผิด

## รูปแบบการแสดงวิธีทำ 7 ขั้น

ทุกข้อ ทุกระดับ แสดงวิธีทำในรูปแบบเดียวกันเสมอ

| ขั้น | เนื้อหา |
|---|---|
| 1. วิเคราะห์โจทย์ | โจทย์ถามอะไร สถานการณ์เป็นอย่างไร และ **"กับดักของข้อนี้"** คืออะไร |
| 2. สิ่งที่โจทย์กำหนด | ตารางสัญลักษณ์ / ค่า / หน่วย / ความหมาย พร้อมสิ่งที่ต้องหา |
| 3. หลักการและสูตรที่ใช้ | สูตรที่เลือก **พร้อมเหตุผลว่าทำไมต้องใช้สูตรนี้** |
| 4. ตั้งสมการและจัดรูป | เขียนสมการจากโจทย์ แล้วจัดให้ตัวที่ต้องการอยู่ข้างเดียว |
| 5. แทนค่า / ดำเนินการ | ใส่ตัวเลขพร้อมวงเล็บ ยังไม่คิดเลข |
| 6. คำนวณ | เดินเลขทีละบรรทัดจนได้ผลลัพธ์ |
| 7. สรุปคำตอบและตรวจสอบ | ประโยคตอบเต็มพร้อมหน่วย และ**วิธีตรวจว่าคำตอบสมเหตุสมผล** |

ในแอพแตะหัวข้อแต่ละขั้นเพื่อเปิด-ปิดได้ (ค่อย ๆ เปิดทีละขั้นแทนการเทเฉลยทั้งหมด)
เวลาพิมพ์ใบเฉลยจะกางครบทุกขั้นให้เอง

**ทุกข้อมีหัวข้อ "กับดักของข้อนี้"** ในขั้นที่ 1 ระบุความเข้าใจผิดที่นักเรียนพลาดบ่อยที่สุดไว้ตรง ๆ
เช่น ใช้ ค.ร.น. แทน ห.ร.ม. · เอาส่วนลดครั้งที่สองไปคิดจากราคาป้าย · ลืมคูณ ½ ในสูตรสามเหลี่ยม

## รูปประกอบโจทย์

โจทย์เรขาคณิต กราฟ และสถิติ มีรูปประกอบที่ **สร้างจากตัวเลขในโจทย์จริง** ไม่ใช่ภาพนิ่งสำเร็จรูป
ตัวเลขเปลี่ยน รูปก็เปลี่ยนตาม

เส้นจำนวน · แถบเศษส่วน · มุมพร้อมส่วนโค้ง (มุมฉากใช้สัญลักษณ์มุมฉาก) ·
สี่เหลี่ยมผืนผ้า · สามเหลี่ยม · คางหมู · ด้านขนาน · วงกลม ·
ทรงสี่เหลี่ยมมุมฉากแบบภาพเฉียง · ระนาบพิกัดฉาก · แผนภูมิแท่ง

รูปทั้งหมดเป็น SVG ที่อ้างสีจากธีม จึงเปลี่ยนตามโหมดสว่าง-มืดเอง และคมชัดเมื่อพิมพ์ลงกระดาษ

> ไฟล์ `outputs/figures-math.html` เป็นหน้ารวมรูปทุกแบบไว้ตรวจด้วยตา
> และ `outputs/preview.html` เป็นตัวอย่างโจทย์และเฉลยครบทั้ง 75 แม่แบบ

## แบบฝึกหัด กับ แบบทดสอบ

ชุดโจทย์มี 2 ประเภท เลือกได้ตอนสร้าง

| | แบบฝึกหัด | แบบทดสอบ |
|---|---|---|
| ตรวจคำตอบ | ทีละข้อทันที | บันทึกไว้ก่อน รู้ผลตอนส่ง |
| บอกถูก/ผิดระหว่างทำ | บอก | **ไม่บอก** |
| วิธีทำ 7 ขั้น | เปิดดูได้ตลอด | **ไม่มีเฉลย** |
| แก้คำตอบ | ตรวจแล้วล็อกคะแนน | **แก้ได้จนกว่าจะกดส่ง** |

### สร้างแบบทดสอบจากแบบฝึกหัด — ตัวเลขจะไม่ซ้ำกัน

กดปุ่ม **สร้างแบบทดสอบ** ที่ชุดแบบฝึกหัดในรายการ จะได้ชุดใหม่ที่ใช้**แม่แบบโจทย์ หัวข้อ
และระดับความยากเดิมทุกข้อ** แต่**ตัวเลขในโจทย์ต่างออกไป** —
ทำแบบฝึกหัดมาก่อนแล้วจำคำตอบไปตอบข้อสอบไม่ได้

> ครูยังพิมพ์**ใบเฉลย**ของแบบทดสอบได้ตามปกติ — ข้อจำกัดเรื่องเฉลยมีเฉพาะฝั่งผู้เรียน

| **สถิติชั้นเรียน** | ค่าเฉลี่ย / SD / การกระจายคะแนน / วิเคราะห์รายข้อ |
| **พิมพ์ / PDF** | ใบงาน ใบเฉลย หลักฐานการเรียนรู้ รายงานชั้นเรียน |
| **ตั้งค่า** | สลับโหมด ค่า π เกณฑ์ผ่าน รายชื่อนักเรียน สำรอง/กู้คืน |

### การสร้างชุดโจทย์

- การ์ดเลือกเรื่อง**จัดกลุ่มตามระดับชั้น** มีปุ่มลัด *เลือกทุกบท* และ *เฉพาะ ม.1*
- **เจาะหัวข้อย่อย** ติ๊กเรื่องแล้วจะมีรายการหัวข้อย่อยขึ้นมา
  *ไม่ติ๊กหัวข้อย่อยเลย = ใช้ทุกหัวข้อในเรื่องนั้น*
- **เลือกระดับ** กด `ทฤษฎี` / `ง่าย` / `ปานกลาง` / `ยาก` แล้วระบุจำนวนข้อ
  หรือกด **รวมระดับ** เพื่อกำหนดจำนวนข้อของแต่ละระดับแยกกัน
- สูงสุด 40 ข้อต่อชุด · ระบบเรียงข้อจากง่ายไปยากให้อัตโนมัติ

### เลขสุ่ม (seed) — จุดสำคัญ

โปรแกรมเก็บแค่ *ชื่อแม่แบบ* กับ *เลขสุ่ม* ของแต่ละข้อ ไม่ได้เก็บตัวโจทย์ไว้
ทำให้ **สร้างชุดเดิมกลับมาได้เป๊ะทุกตัวเลขเสมอ** จึงพิมพ์ใบงานแจกวันนี้
แล้วพิมพ์ใบเฉลยที่ตรงกับใบงานใบนั้นเมื่อไรก็ได้ และย้อนดูหลักฐานการเรียนรู้ปีหน้าก็ยังตรงกัน

## การวิเคราะห์ผู้เรียน

แท็บ **ผลและวิเคราะห์** แยกผลออกเป็น 4 มุม

1. **ตามเรื่อง** — เรื่องไหนแข็ง เรื่องไหนอ่อน
2. **ตามระดับความยาก** — ง่ายยังพลาด (ไม่แม่นนิยาม) หรือเฉพาะข้อยากที่พลาด (ตั้งสมการไม่เป็น)
3. **ตามหัวข้อย่อย** — ระบุได้ว่าต้องกลับไปทบทวนหัวข้อไหน
4. **ตามทักษะ** — โจทย์ทุกข้อติดป้ายทักษะไว้ เช่น *ระบุฐานของร้อยละ*, *ย้ายข้างเปลี่ยนเครื่องหมาย*,
   *ใช้ความสูงที่ตั้งฉากกับฐาน*, *เลือกใช้ ห.ร.ม. หรือ ค.ร.น.*
   ทำให้เห็นว่าปัญหาอยู่ที่ทักษะร่วม ไม่ใช่แค่หัวข้อใดหัวข้อหนึ่ง

พร้อม **ข้อเสนอแนะอัตโนมัติ** ที่ดูจากคะแนน ทักษะที่อ่อน จำนวนครั้งที่เปิดเฉลย และเวลาที่ใช้ต่อข้อ

## สถิติชั้นเรียน (โหมดครู)

- ค่าเฉลี่ย มัธยฐาน ส่วนเบี่ยงเบนมาตรฐาน สูงสุด-ต่ำสุด จำนวนผู้ผ่านเกณฑ์
- กราฟการกระจายคะแนนเป็นช่วงละ 10%
- ตารางผลรายคน พร้อมคอลัมน์ *หัวข้อที่ต่ำกว่าเกณฑ์* ของแต่ละคน
- **วิเคราะห์รายข้อ** — ค่าความยาก **p** (เหมาะสม 0.20–0.80) และอำนาจจำแนก **r** (ควร ≥ 0.20)
- **ประเด็นที่ควรสอนซ่อมเสริม** — หัวข้อที่ทั้งห้องทำได้ต่ำกว่า 50% และรายชื่อผู้ที่ควรช่วยเหลือ

## การพิมพ์และการทำไฟล์ PDF

| เอกสาร | ใช้ทำอะไร |
|---|---|
| **ใบงาน** | โจทย์อย่างเดียว มีหัวกระดาษ ชื่อ-เลขที่-ชั้น-วันที่ และกรอบขั้นตอนให้เขียนตาม |
| **ใบเฉลย** | แสดงวิธีทำครบ 7 ขั้นทุกข้อ พร้อมคำตอบ |
| **หลักฐานการเรียนรู้** | สรุปผลรายคน จุดแข็ง-จุดที่ต้องพัฒนา ผลรายข้อ และช่องลงนามผู้เรียน/ครู |
| **รายงานสถิติชั้นเรียน** | สถิติภาพรวม กราฟการกระจาย ผลรายคน วิเคราะห์รายข้อ และประเด็นสอนซ่อม |

### กรอบเขียนวิธีทำในใบงาน

ในใบงานที่พิมพ์ ขั้นที่ทำต่อเนื่องกันจะถูก**ยุบรวมเป็นช่องเดียว** เพื่อให้นักเรียนเขียนได้ลื่นขึ้น

| ช่อง | ตรงกับขั้น | บรรทัดเขียน (ค่าเริ่มต้น) |
|---|---|---|
| 1. วิเคราะห์โจทย์ / สิ่งที่กำหนด | รวมขั้นที่ 1-2 | 3 |
| 2. หลักการที่ใช้ / ตั้งสมการ | รวมขั้นที่ 3-4 | 4 |
| 3. แทนค่า / ดำเนินการ | ขั้นที่ 5 | 1 |
| 4. คำนวณ | ขั้นที่ 6 | 3 |
| 5. สรุปคำตอบและตรวจสอบ | ขั้นที่ 7 | 1 |

ปรับจำนวนบรรทัดของแต่ละช่องได้อิสระ (0–12 บรรทัด) ที่แท็บ **ตั้งค่า**
ตั้งเป็น **0** = ไม่ต้องมีช่องนั้นในใบงาน

### วิธีได้ไฟล์ PDF

- **บนไอแพด** — กด *พิมพ์ / บันทึกเป็น PDF* → เลือก **แชร์** หรือ **บันทึกลงในไฟล์**
- **บนคอมพิวเตอร์** — ในช่อง *เครื่องพิมพ์* เลือก **บันทึกเป็น PDF** หรือ **Microsoft Print to PDF**

> ตั้งขนาดกระดาษ **A4** และปิด *หัวกระดาษและท้ายกระดาษ* ของเบราว์เซอร์ จะได้เอกสารสวยที่สุด

## ค่าคงที่และเกณฑ์

- **ค่า π** เลือก `3.14` หรือ `22/7`
  เลือก **22/7** เมื่อรัศมีในโจทย์เป็นพหุคูณของ 7 จะได้คำตอบลงตัวสวยกว่า
  (ยังไม่มีผลกับคลัง ม.1 แต่จะใช้กับบทวงกลม ทรงกระบอก กรวย และทรงกลมในเฟสถัดไป)
- **ยอมคลาดเคลื่อน** ค่าเริ่มต้น 1% — มีผลเฉพาะคำตอบชนิดทศนิยม
  ส่วนคำตอบจำนวนเต็มและเศษส่วนต้องตรงเป๊ะเสมอ
- **เกณฑ์ผ่าน** ค่าเริ่มต้น 60%

> การเปลี่ยนค่า π มีผลกับชุดที่สร้าง **หลังจากนี้** เท่านั้น
> ชุดเดิมจำค่าที่ใช้ตอนสร้างไว้ ทำให้พิมพ์เฉลยย้อนหลังได้ตรงกันเสมอ

## การเก็บข้อมูลและการสำรอง ⚠️

ข้อมูลบันทึกอัตโนมัติลงในเบราว์เซอร์ของเครื่องนี้ (localStorage) ทุกครั้งที่แก้ไข
โดยเก็บไว้คนละที่กับแอพฟิสิกส์ **ข้อมูลของสองวิชาจึงไม่ทับกัน**

**ข้อมูลจะหายถ้า:** ล้างข้อมูลการท่องเว็บ, ใช้โหมดไม่ระบุตัวตน, เปลี่ยนเบราว์เซอร์ หรือย้ายเครื่อง —
ข้อมูล **ไม่ได้** ฝังอยู่ในไฟล์ `math.html`

- กด **สำรอง** เพื่อดาวน์โหลดไฟล์ `.json` เก็บไว้ — แนะนำให้ทำทุกครั้งหลังใช้งานเสร็จ
- กด **กู้คืน** เพื่อโหลดไฟล์สำรองกลับ (จะทับข้อมูลปัจจุบันทั้งหมด)

## สำหรับผู้ดูแลโค้ด

### ตรวจคลังโจทย์

เปิด `math.html?selftest=1` จะวนสร้างทุกแม่แบบ 200 ชุดตัวเลข แล้วตรวจว่า

- สร้างโจทย์ได้ทุกชุดตัวเลข ไม่มี `undefined` / `NaN` หลุดในโจทย์หรือเฉลย
- คำตอบอยู่ในรูปที่กำหนดไว้ (จำนวนเต็ม · ทศนิยมไม่เกิน 2 ตำแหน่ง · เศษส่วนอย่างต่ำที่ตัวส่วนไม่เกิน 24)
- วิธีทำครบ 7 ขั้น (ข้อทฤษฎี 3 ขั้น) ไม่มีขั้นไหนว่าง
- ตัวเลือกปรนัยครบ 4 ไม่ซ้ำ และถูกเพียงตัวเดียว
- ทุกเรื่องมีแม่แบบครบทุกระดับ อย่างน้อยระดับละ 3 ตัว

### วิธีเพิ่มบทใหม่

1. เพิ่มหนึ่งบรรทัดในอาเรย์ `TOPICS` เช่น `{ id: 201, grade: 2, ch: 1, icon: '🔢', name: '…' }`
   **ห้ามเปลี่ยน id เดิม** เพราะชุดโจทย์เก่าอ้างถึงอยู่
2. เพิ่มบล็อก `T({ topic: 201, … })` และ `TQ({ … })` ในส่วนคลังแม่แบบ ให้ครบทุกระดับ
3. เติมสูตรของบทนั้นใน `FORMULAS` โดยใช้ id เดียวกันเป็นคีย์
4. เปิด `math.html?selftest=1` ตรวจให้ผ่าน 0 ข้อผิดพลาด

หน้าเลือกเรื่อง สถิติ การวิเคราะห์ และเอกสารพิมพ์ อ่านจาก `TOPICS` กับ `TPL` ทั้งหมด
ไม่ต้องแก้ที่อื่นอีก และปุ่มชุดลัดของระดับชั้นใหม่จะโผล่มาเอง

### ข้อควรระวังเรื่องชื่อคลาสในรูป SVG

คลาสของรูปทุกตัวขึ้นต้นด้วย `f` (`fbar` `fbox` `ffil` `fgrd` `fpt`) โดยตั้งใจ
เพราะเบราว์เซอร์ถือว่า `width` / `height` ของ SVG เป็นสมบัติ CSS ด้วย
ถ้าชื่อคลาสไปชนกับคลาสของหน้าเว็บ (เช่น `.bar{height:9px}` ของแถบสถิติ)
ความสูงของแท่งกราฟจะถูกทับจนกลายเป็นขีดสั้น ๆ ลอยอยู่กลางอากาศ
