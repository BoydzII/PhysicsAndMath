# ส่งงานออนไลน์ (WorkDesk)

นักเรียนถ่ายรูปใบงานหรือแนบ PDF ส่งครูจากมือถือ ครูตรวจ ให้คะแนน และดูนักเรียนที่ต้องติดตามได้ในหน้าเดียว
ไฟล์เดียว `index.html` ใช้ทั้งครูและนักเรียน แอปเลือกหน้าจอเองจากบทบาทที่ลงชื่อไว้ที่หน้าพอร์ทัล

ลิงก์: **https://boydzii.github.io/PhysicsAndMath/WorkDesk/** (หรือกดการ์ด “ส่งงานออนไลน์” ที่หน้าพอร์ทัล)

## ชีตที่ใช้ (ชีตรุ่น 20)

| ชีต | เก็บอะไร |
|---|---|
| **ชีตวิทยาศาสตร์กายภาพ** (ศูนย์กลาง) | รหัสผ่านทุกคน · คำขอลืมรหัสผ่าน |
| **ชีตส่งงาน** (สำเนาของศูนย์กลาง) | งานที่สั่ง · การส่ง · คะแนน · ไฟล์ใน Drive |

แยกกันเพื่อให้การอัปโหลดไฟล์ไม่ถ่วงการลงชื่อเข้าใช้ของทั้งโรงเรียน
ที่อยู่ของชีตส่งงานอยู่ใน `BOOKS` ของหน้าพอร์ทัล (ใบที่มี `autoRoster`) และ `WORK_URL` ในไฟล์นี้ ต้องตรงกัน

ชีตส่งงาน**รับรายชื่อนักเรียนจากชีตศูนย์กลางเอง** ตอนนักเรียนลงชื่อ (เพิ่มคนใหม่ อัปเดตชั้นที่ย้าย)
และ**ไม่รับรหัสผ่านตรง** รับเฉพาะการลงชื่อผ่านหน้าพอร์ทัล
ครูผู้สอนต้องมีบัญชีในแผ่น teachers ของชีตส่งงานด้วย (สำเนามาแล้วตอนสร้าง ถ้าเพิ่มครูใหม่ต้องเพิ่มทั้งสองชีต)

### ติดตั้ง (ผู้ดูแลหลัก ทำครั้งเดียว)

1. วาง [`PhysicsAutoSheet/appsscript-Code.gs`](../PhysicsAutoSheet/appsscript-Code.gs) รุ่น 20 ใน Apps Script ของ **ทั้งสองชีต**
   (แก้ `DEFAULT_ADMIN_PASS` เป็นรหัสจริงในหน้า Apps Script เท่านั้น)
   แล้ว **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ทีละชีต
2. ชีตส่งงานใช้ Google Drive — ถ้ายังไม่เคยอนุญาต ให้เลือกฟังก์ชัน **`doGet`** กด **เรียกใช้** แล้วกดอนุญาต
   (อย่าใช้ `setupFirstTime` กับชีตที่ใช้งานอยู่ เพราะจะตั้งรหัสผู้ดูแลทับ)
3. เข้าหน้าพอร์ทัลเป็นผู้ดูแลหลัก → กล่อง "รหัสเดียวทุกวิชา" → กด **เชื่อมทุกชีต** ให้ขึ้น ✓ ครบทั้งสามชีต
4. ออกจากระบบแล้วลงชื่อใหม่หนึ่งครั้ง

แผ่นใหม่ `works` `worksubs` ถูกสร้างให้เองตอนใช้ครั้งแรก
ไฟล์งานเก็บในโฟลเดอร์ **“งานที่นักเรียนส่ง · (ชื่อชีตส่งงาน)”** ใน Drive ของเจ้าของชีต แยกโฟลเดอร์ตามงาน

## ครู

| แท็บ | ทำอะไร |
|---|---|
| **งานที่สั่ง** | สั่งงานใหม่ เลือกชั้น กำหนดส่ง คะแนนเต็ม และการให้คะแนน · ดูว่าส่งกี่คน ช้ากี่คน รอตรวจกี่คน · **กรองตามวิชาและห้อง** · **ติ๊กเลือกหลายงานแล้วลบพร้อมกัน** |
| **ตรวจงาน** | ดูรูปทีละคน ใส่คะแนน กด Enter ไปคนถัดไป · ให้คะแนนเท่ากันทุกคนที่ส่งในปุ่มเดียว · คัดลอกคะแนนไปวาง Excel · **กรองห้อง** (งานที่สั่งหลายห้อง) · **แจ้งเตือนนักเรียน** |
| **คะแนนรวมรายวิชา** | ตารางทุกคน × ทุกงานของวิชาที่เลือก (หรือทุกวิชา) กรองห้องได้ · รวมคะแนน ร้อยละ จำนวนครั้งที่ส่งตรง/ช้า/ขาด · คัดลอกไปวาง Excel |
| **นักเรียนที่ต้องติดตาม** | รายชื่อคนที่เสี่ยงติด 0 หรือค้างส่งหลายงาน รายชั้น · คัดลอกส่งครูที่ปรึกษาได้ |
| **ปลดล็อกรหัส** | **ศูนย์กลางของทุกแอป** — คนที่ถูกพักเพราะกรอกรหัสผิดในทุกแอป · คำขอตั้งรหัสใหม่ · ปลดทันที |

### เขียนตรวจงาน · ลายเซ็นครู (ชีตรุ่น 24)

ในตัวดูงาน (แท็บ **ตรวจงาน** → กดชื่อนักเรียน) กดปุ่ม **✏️ เขียนตรวจ** จะเปิดหน้าเขียนแบบสมุดโน้ต

| เครื่องมือ | ใช้อย่างไร |
|---|---|
| ปากกา · ปากกาเน้นข้อความ | 5 สี 3 ขนาด · Apple Pencil มีน้ำหนักเส้นตามแรงกด |
| ยางลบ | ลบทีละเส้น · ย้อนกลับ/ทำซ้ำได้ (Ctrl+Z / Ctrl+Y) |
| ✓ ✗ · คะแนน · ดีมาก · ข้อความ | แปะลงบนงาน · ปุ่ม **คะแนน** ใช้ตัวเลขในช่องคะแนนด้านล่างของหน้าเขียนตรวจ · เครื่องมือ **ข้อความ** แตะตรงที่จะใส่แล้วพิมพ์ |
| ลายเซ็น | เซ็นครั้งแรกในกรอบ (หรือเลือกรูปลายเซ็นที่ถ่ายไว้ ระบบตัดพื้นขาวให้) · บันทึกไว้ในชีต ใช้ได้ทุกเครื่อง · ใส่วันที่ตรวจใต้ลายเซ็นได้ |
| ย้าย | ลากของที่แปะไปวาง · ลากมุมขวาล่างเพื่อย่อขยาย · กด × เพื่อเอาออก |
| ซูม | ปุ่ม − / + · สองนิ้วบนไอแพด · Ctrl+ล้อเมาส์ |

- ใช้ Apple Pencil: พอระบบเจอปากกา **นิ้วจะเปลี่ยนเป็นเลื่อน/ซูมหน้า** ฝ่ามือวางบนจอได้ ไม่เป็นเส้น (สลับได้ที่ปุ่มรูปมือ)
- งาน PDF แปลงเป็นหน้า ๆ ให้เขียนได้เหมือนรูป
- กด **บันทึก · คนถัดไป** — ระบบรวมเป็นรูปทีละหน้า (ส่งเบื้องหลัง ดูหัวข้อถัดไป) นักเรียนเห็นหัวข้อ **งานที่ครูเขียนตรวจ** ในหน้าส่งงาน เปิดดูและดาวน์โหลดได้
- เปิดเขียนตรวจอีกครั้งจะแก้ต่อจากฉบับที่บันทึกไว้ หรือกด **เริ่มใหม่จากต้นฉบับ** / **ลบฉบับที่เขียนตรวจ**
- ไฟล์อยู่ในโฟลเดอร์ของงานนั้นใน Drive (ชื่อไฟล์มีคำว่า `_ตรวจ_`) · ลายเซ็นอยู่ในโฟลเดอร์ **ลายเซ็นครู**

### ตรวจต่อเนื่อง · ส่งเบื้องหลัง (ชีตรุ่น 25)

ตรวจได้ลื่นเหมือนพลิกกระดาษ — ไม่ต้องรอชีตตอบก่อนไปคนถัดไป

- หน้าเขียนตรวจมีช่อง **คะแนน · ความเห็น** ด้านล่าง กด **บันทึก · คนถัดไป ›** (หรือ Enter ในช่องคะแนน · Ctrl+Enter) แล้วคนถัดไปที่ยังรอตรวจขึ้นทันที ปากกา สี ซูม ยังเหมือนเดิม
- ปุ่ม **‹ ก่อนหน้า / ถัดไป ›** และปุ่ม **ปิด** เก็บสิ่งที่เพิ่งเขียนและคะแนนให้เองด้วย
- งานที่บันทึกเข้า **คิวส่งเบื้องหลัง** (ส่งพร้อมกันสองคน) มุมขวาล่างบอกว่า "กำลังส่ง … คน" → "ส่งครบแล้ว ✓"
  - คิวเก็บในเครื่อง ปิดหน้า เน็ตหลุด หรือหมดเวลาเข้าใช้ งานไม่หาย เปิดหน้าส่งงานอีกครั้งจะส่งต่อให้เอง
  - ส่งไม่ผ่านระบบลองใหม่เอง 3 ครั้ง ถ้ายังไม่ผ่านจะขึ้นปุ่ม **ส่งไม่ผ่าน … คน · ลองใหม่**
- ระหว่างตรวจคนหนึ่ง ระบบโหลด (และแปลง PDF) ของอีกสองคนถัดไปรอไว้
- ปุ่ม **บันทึก · คนถัดไป** ในตัวดูงาน (ไม่เขียนตรวจ ให้แค่คะแนน) ก็ส่งเบื้องหลังเหมือนกัน
- รูปที่ส่งให้นักเรียนย่อด้านยาวเหลือ 1600 พิกเซล ลายมือยังคม ไฟล์เล็กลงส่งเร็วขึ้น

ชีตรุ่น 25 รวมหน้า คะแนน และความเห็นเป็นคำขอเดียว (`workMarkSave`) ชีตรุ่น 24 ยังใช้ได้แต่ส่งช้ากว่า (ทีละหน้า)

### นักเรียนเห็นเลขที่เพื่อนที่ส่งแล้ว (ชีตรุ่น 24)

หน้างานของนักเรียนมีหัวข้อ **เพื่อนในห้อง** — เลขที่ของทุกคนในห้อง **สีเขียว = ส่งแล้ว สีแดง = ยังไม่ส่ง** (กรอบดำคือตัวเอง)
แสดงเฉพาะเลขที่ ไม่มีชื่อ ไม่มีคะแนน ให้นักเรียนช่วยกันตามงาน · ส่งเป็นกระดาษแล้วครูให้คะแนนก็นับเป็นส่งแล้ว

ต้องวาง `appsscript-Code.gs` **รุ่น 25** ที่ **ชีตส่งงาน** แล้ว Deploy เวอร์ชันใหม่ (ชีตอื่นไม่ต้องเปลี่ยน)

### แจ้งเตือนนักเรียน (ชีตรุ่น 22)

ในแท็บ **ตรวจงาน** มีปุ่มสามกลุ่ม นับจากสถานะจริงของงานนั้น (และห้องที่กรองไว้)

| ปุ่ม | ใคร | ข้อความตั้งต้น (แก้ได้ก่อนส่ง) |
|---|---|---|
| 🔔 **ขาดส่ง** | เลยกำหนดแล้วยังไม่ส่ง และครูยังไม่ได้ให้คะแนน | บอกให้รีบส่ง ระบบยังเปิดรับ |
| ⏰ **ส่งไม่ตรงกำหนด** | ส่งไฟล์หลังกำหนด | ได้รับแล้ว ครั้งหน้าให้ทันเวลา |
| 🌟 **ส่งตรงกำหนด** | ส่งไฟล์ทันกำหนด | ชมเชย |

นักเรียนเห็นข้อความบนสุดของหน้าส่งงานจนกว่าจะกด **รับทราบ** (เก็บในแผ่น `worknotes` ครูดูคอลัมน์ "อ่านเมื่อ" ได้ว่าใครอ่านแล้ว)
ชีตเลือกคนจากสถานะจริงอีกรอบตอนกดส่ง จึงไม่มีทางเตือนผิดคน · มีปุ่ม **คัดลอกรายชื่อ** ไว้ส่งต่อทาง LINE ด้วย

### คะแนนรวมรายวิชา (ชีตรุ่น 22)

ช่องในตารางแสดง **คะแนน** ถ้าตรวจแล้ว ไม่งั้นแสดงสถานะ: รอตรวจ · ขาด · ยังไม่ถึง (กำหนด) · กระดาษ (ไม่มีไฟล์ ครูยังไม่ให้คะแนน)
**รวม** = คะแนนที่ได้ ÷ เต็มของงานที่ตรวจแล้วรวมกับงานที่ขาดส่ง (ขาดส่งนับ 0 · ส่งแล้วรอตรวจยังไม่นับ จะได้ไม่ลงโทษคนที่ส่งแล้ว)
แถวล่างสุดคือค่าเฉลี่ยของกลุ่มที่แสดงอยู่ · วิชามาจากช่อง “วิชา” ตอนสั่งงาน งานที่ไม่ได้ใส่วิชารวมอยู่ใน “ไม่ระบุวิชา”

ต้องวาง `appsscript-Code.gs` **รุ่น 22** ที่ **ชีตส่งงาน** แล้ว Deploy เวอร์ชันใหม่ (ชีตศูนย์กลางและชีตฟิสิกส์ไม่ต้องเปลี่ยน)

### ใบงานให้นักเรียนโหลด (ชีตรุ่น 21)

ในฟอร์มสั่งงาน/แก้ไขงาน กด **แทรกใบงาน** เลือกได้หลายไฟล์ — PDF รูป Word Excel PowerPoint ไม่เกิน 10 MB ต่อไฟล์ สูงสุด 10 ไฟล์ต่องาน
ไฟล์อัปโหลดตอนกดบันทึก ใบงานเดิมกด **เอาออก** ได้ (ไฟล์ย้ายไปถังขยะของ Drive กู้คืนได้ 30 วัน)
นักเรียนเห็นป้าย “มีใบงาน” ที่รายการงาน เปิดงานแล้วกด **เปิด / โหลด** ดู PDF หรือรูปในหน้า และกด **ดาวน์โหลดลงเครื่อง** ได้
ไฟล์ Word Excel PowerPoint ดูในหน้าไม่ได้ ต้องดาวน์โหลดไปเปิดด้วยแอปในเครื่อง
เปิดได้เฉพาะนักเรียนในชั้นที่สั่งงานนั้นและครูที่เห็นงานนั้น ไฟล์ใน Drive ไม่ได้แชร์ให้ใคร

ต้องวาง `appsscript-Code.gs` รุ่น 21 ที่ **ชีตส่งงาน** แล้ว Deploy เวอร์ชันใหม่ (ชีตศูนย์กลางไม่ต้องเปลี่ยน)
คอลัมน์ “ใบงานจากครู” ต่อท้ายแผ่น works ถูกเติมให้เองตอนใช้ครั้งแรก

### การให้คะแนน (เลือกต่องาน)

- **คะแนนเท่ากัน ไม่ว่าส่งเมื่อไร** — ส่งช้าได้คะแนนตามที่ครูให้ ไม่หัก
- **ตามเวลาที่ส่ง** — หักวันละกี่เปอร์เซ็นต์ และหักรวมไม่เกินเท่าไร
  ช้าไม่ถึงวันนับเป็นหนึ่งวัน (ช้า 1 นาทีก็หักวันแรก)

**ไม่มีปิดรับ** นักเรียนส่งได้ตลอด ส่งหลังกำหนดจะขึ้นว่า “คุณส่งช้ากว่ากำหนด …” ทั้งก่อนกดส่งและหลังส่ง
ครูเลื่อนกำหนดส่งทีหลัง คะแนนที่หักคิดใหม่ให้เองทันที
นักเรียนส่งใหม่ได้ ไฟล์ชุดใหม่แทนชุดเดิม (ชุดเดิมย้ายไปถังขยะของ Drive กู้คืนได้ 30 วัน) และเวลาส่งนับจากครั้งล่าสุด

### นักเรียนที่ต้องติดตาม

คิดจากงานที่ **เลยกำหนดส่งแล้ว** เท่านั้น
- **เสี่ยงติด 0** — มีงานเลยกำหนดอย่างน้อย 2 งาน และ ค้างส่งตั้งแต่ครึ่งหนึ่ง หรือคะแนนงานต่ำกว่าร้อยละ 50
  (งานที่ค้างนับเป็น 0 · งานที่ส่งแล้วแต่ครูยังไม่ตรวจไม่นับ)
- **ค้างส่งหลายงาน** — ค้างตั้งแต่ 2 งาน

นักเรียนเห็นคำเตือนเดียวกันที่หน้าส่งงานของตัวเอง

## ศูนย์ปลดล็อกรหัส (ทุกแอป)

แท็บ **ปลดล็อกรหัส** รวมเรื่องรหัสของทุกแอปในเครือไว้ที่เดียว ครูไม่ต้องเข้าไปปลดในแต่ละแอปอีก
ลิงก์ตรง: `WorkDesk/index.html#reset` · หน้าหลักขึ้นแถบแจ้งครูเมื่อมีคนถูกพักหรือมีคำขอรออยู่ · ในแอปวิชามีลิงก์มาที่นี่ด้วย

**1) ถูกพักเพราะกรอกรหัสผิด** — ระบบพักการเข้าใช้สิบนาทีเมื่อกรอกผิดหลายครั้ง ตัวนับอยู่ในแต่ละชีตที่รับรหัสผ่าน

| ชีต | แอปที่ใช้ |
|---|---|
| ชีตศูนย์กลาง (วิทยาศาสตร์กายภาพ) | หน้าหลัก · คณิต · วิทย์ · เคมี · ชีวะ · วิทย์กายภาพ · สมดุลกล · ปรับพื้นฐาน |
| ชีตฟิสิกส์ | ฟิสิกส์ ม.4 |

แท็บนี้ดึงจากทุกชีตพร้อมกันแล้วรวมเป็นรายคน กด **ปลด** ทีเดียวล้างตัวนับทุกชีตที่คนนั้นติดอยู่ (ไม่ได้เปลี่ยนรหัส)
ชีตส่งงานไม่อยู่ในรายการเพราะไม่รับรหัสผ่านตรง · ที่อยู่ของชีตทั้งสองอยู่ใน `LOCK_BOOKS` ใน index.html ของแอปนี้ ต้องตรงกับ `BOOKS` ในหน้าพอร์ทัล

**2) ลืมรหัสผ่าน** — นักเรียนกด **ลืมรหัสผ่าน?** ที่หน้าลงชื่อเข้าใช้ของพอร์ทัล → กรอกเลขประจำตัว ชื่อจริง และ **ตั้งรหัสใหม่เอง**
คำขอไปรอในแท็บเดียวกัน ครูเลือกได้สามแบบ

| แบบ | ใช้เมื่อ |
|---|---|
| **ปลด** (รายคน) | ตรวจชื่อแล้วอนุมัติทีละคน |
| **ปลดทั้งหมด** | อนุมัติทุกคำขอที่รออยู่ในชั้นที่ตัวเองดูแล |
| **ปลดทันที** | เปิดช่วง 10–60 นาทีตอนอยู่ในห้อง คำขอที่เข้ามาในช่วงนั้นใช้ได้ทันที ปิดเองเมื่อหมดเวลา |

อนุมัติแล้วนักเรียนเข้าด้วยรหัสใหม่ที่ตั้งไว้ตอนยื่น — **ครูไม่ต้องรู้หรือบอกรหัสใคร**
ใครยื่นขณะมีคำขอรออยู่ ข้อความรหัสผิดจะบอกว่า “มีคำขอรอครูอนุมัติ” จะได้ไม่ยื่นซ้ำ
ครูผู้สอนเห็นและปลดได้เฉพาะชั้นที่ตัวเองดูแล

## ความปลอดภัยที่ควรรู้

- ไฟล์ใน Drive ไม่ได้แชร์ให้ใคร เปิดได้ผ่านหน้านี้เท่านั้น ชีตตรวจทุกครั้งว่าเป็นเจ้าของไฟล์ หรือครูที่ดูแลชั้นของเจ้าของไฟล์
- ส่งไฟล์ได้เฉพาะรูป (JPG PNG WEBP) กับ PDF ไม่เกิน 10 MB ต่อไฟล์ รูปถูกย่อในเครื่องก่อนส่ง (ด้านยาว 1600 px)
- คำขอรหัสผ่านต้องกรอกชื่อให้ตรงกับเลขประจำตัว และยื่นได้ไม่เกินสามครั้งต่อชั่วโมง
- ช่วง **ปลดทันที** ใครรู้เลขประจำตัวกับชื่อของเพื่อนก็เปลี่ยนรหัสเพื่อนได้ จึงควรเปิดเฉพาะตอนอยู่ในห้อง

## ทดสอบในเครื่อง

เปิดจาก `localhost` แล้วใส่ `?api=<ที่อยู่ชีตจำลอง>` เพื่อไม่ให้ไปแตะชีตจริง
พารามิเตอร์นี้ไม่มีผลเมื่อเปิดจากเว็บจริง
