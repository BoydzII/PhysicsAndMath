# สกิลการสร้างแบบฝึกหัดฟิสิกส์แบบโต้ตอบ (Physics Interactive Workbook Skill)

เอกสารนี้กำหนดมาตรฐานการสร้างและการพัฒนาแอปพลิเคชันแบบฝึกหัดฟิสิกส์แบบอินเทอร์แอคทีฟ (Interactive Digital Physics Workbook) สำหรับโรงเรียนและห้องเรียนฟิสิกส์ยุคใหม่ (เช่น `Physics2App`)

---

## 1. ปรัชญาการออกแบบแอปพลิเคชัน (Core Design Principles)

1. **การทำงานร่วมกันระหว่าง DOM และ Canvas (Dual-Layer Sync):**
   - **ชั้นล่าง (DOM Layer):** ข้อความโจทย์, รูปภาพ/SVG ประกอบ, การแสดงวิธีทำด้วยสมการ KaTeX, และช่องรับคำตอบ `<input class="answer-input">`
   - **ชั้นบน (Digital Ink Canvas):** วาดทับแผ่นกระดาษเพื่อให้นักเรียนสามารถทดเลข, วาดเวกเตอร์, ขีดเขียนแนวคิดได้อย่างอิสระเสมือนกระดาษจริง
   - **Pointer Events Pass-Through:** ให้ `.notebook-paper` มี `pointer-events: none` และให้อินพุตหรือปุ่มในกระดาษมี `pointer-events: auto` เพื่อให้การจดลายมือและการกรอกคำตอบทำงานร่วมกันได้อย่างราบรื่น

2. **ระบบการย่อ-ขยายเฉพาะแผ่นงาน (Sheet-Only Responsive Zoom):**
   - การซูมต้องมุ่งเป้าเฉพาะตัวกระดาษ (`.notebook-wrapper`) เพื่อให้นักเรียนขยายดูโจทย์หรือเขียนตัวหนังสือเล็กๆ ได้อย่างถนัด
   - UI Chrome อื่นๆ (Topbar เลือกระดับ/หัวข้อ, แถบทฤษฎีและการทดลองจำลองซ้ายมือ, กล่องเครื่องมือปากกา) ต้องคงที่อยู่กับที่ ไม่ขยายตามจนล้นจอ
   - การคำนวณตำแหน่งปลายปากกา ต้องไม่คลาดเคลื่อนไม่ว่าจะซูมอยู่ที่ระดับใด (0.7x ถึง 2.5x)

3. **การแบ่งระดับการเรียนรู้ 3 ระดับ (3-Tier Scaffolding):**
   - **ระดับพื้นฐาน (Beginner):** มีโครงสร้างวิธีทำละเอียด (.calc-steps 3 คอลัมน์) พร้อมบอกสูตรและขั้นตอนการคิด
   - **ระดับปานกลาง (Intermediate):** สรุปตัวแปรที่โจทย์กำหนดให้และต้องการหา พร้อมช่องกรอกคำตอบ
   - **ระดับขั้นสูง (Advanced / Challenge):** แสดงเฉพาะโจทย์ล้วนและภาพประกอบ เพื่อฝึกทักษะการวิเคราะห์และแก้ปัญหาด้วยตนเอง

4. **การตรวจคำตอบแบบทนทาน (Robust Answer Evaluation):**
   - รองรับคำตอบหลายรูปแบบ (เช่น ทศนิยม, ค่าติดรูท, ตัวเลขติดเครื่องหมายลบ)
   - ปัดเศษและยอมรับค่าคลาดเคลื่อนทางทศนิยมที่สมเหตุสมผล (Tolerance $\pm 2\%$)
   - ไม่บล็อกนักเรียนด้วยการตรวจแบบ String Match ธรรมดา

## 2. เช็คลิสต์ก่อนส่งมอบงาน (Definition of Done)
- [ ] กระดาษทำโจทย์สามารถซูมเข้า-ออก และรีเซ็ตเป็น 100% ได้ลื่นไหล
- [ ] สมการทางคณิตศาสตร์และฟิสิกส์เรนเดอร์ผ่าน KaTeX 100% โดยไม่มี Raw LaTeX ตกค้าง
- [ ] ตัวแปรและหน่วยฟิสิกส์ถูกต้องตามหลัก ISO 80000-2
- [ ] ลายมือดิจิทัลคมชัดระดับ Retina (High-DPI) ไม่หลุด ไม่กระตุกที่ 120 FPS
- [ ] ระบบบันทึกข้อมูล (คำตอบและลายมือ) ลง LocalStorage แยกตามหัวข้ออย่างปลอดภัย
