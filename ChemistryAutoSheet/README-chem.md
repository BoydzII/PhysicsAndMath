## สิ่งที่เคมีต่างจากคณิตและฟิสิกส์

**คำตอบชนิด "ตรงเป๊ะ"** — โจทย์เรื่อง<b>เลขนัยสำคัญ</b>ตั้งคำตอบเป็นชนิด `exact`
ซึ่งไม่ผ่อนตามค่า *ยอมคลาดเคลื่อน* ที่ตั้งไว้ในแท็บตั้งค่า
เพราะประเด็นของบทนั้นคือการปัดให้ถูกตำแหน่งพอดี ถ้ายอมคลาดเคลื่อนก็ไม่ได้วัดอะไรเลย

**โจทย์รหัสตัวเลข** — บางเรื่องคำตอบเป็นข้อความ เช่น *ชนิดพันธะ* หรือ *ชนิดแรงระหว่างโมเลกุล*
ซึ่งกรอกเป็นตัวเลขไม่ได้ตรง ๆ จึงออกแบบให้ตอบเป็น**จำนวนนับ**แทน เช่น
"มีกี่สารที่เกิดพันธะไฮโดรเจนได้" หรือ "มีกี่โมเลกุลที่มีขั้ว"
วิธีนี้ยังวัดทักษะเดิมได้ครบ แต่ตรวจอัตโนมัติได้และมีตัวเลือกให้เลือกครบสี่ข้อ

**ค่าคงที่** — บทเทอม 1 ยังไม่ใช้ค่าคงที่ที่ครูต้องเลือก การ์ด *ค่าคงที่และเกณฑ์*
จึงแสดงเฉพาะมวลอะตอมที่โจทย์ใช้และเลขอาโวกาโดรไว้อ้างอิง

## รูปประกอบโจทย์ — 7 แบบ

| ฟังก์ชัน | ใช้กับ |
|---|---|
| `figLabGlass` | กระบอกตวงพร้อมสเกลและผิวโค้งเว้า — ใช้กับเลขนัยสำคัญและการอ่านค่า |
| `figAtomShell` | แบบจำลองอะตอมแบบวงโคจร พร้อมจำนวนโปรตอนและนิวตรอน |
| `figPeriodicMini` | ตารางธาตุ 20 ธาตุแรก ระบายช่องที่โจทย์พูดถึง พร้อมลูกศรแนวโน้ม |
| `figLewis` | โครงสร้างลิวอิส พันธะเดี่ยว-คู่-สาม และคู่โดดเดี่ยว |
| `figShape` | รูปร่างโมเลกุลตาม VSEPR พร้อมมุมพันธะและคู่โดดเดี่ยว |
| `figIonic` | การถ่ายโอนอิเล็กตรอนของพันธะไอออนิก |
| `figBar` | แผนภูมิแท่ง — ใช้กับค่าพลังงานไอออไนเซชันและมวลโมเลกุล |

รูปทุกรูป**วาดตามตัวเลขจริงของโจทย์** ไม่ใช่รูปประกอบลอย ๆ เช่น
มุมพันธะของ `figShape` กางตามค่าที่โจทย์ถาม และช่องที่ระบายใน `figPeriodicMini`
ตรงกับธาตุที่โจทย์กล่าวถึงจริง

> `outputs/figures-chem.html` เป็นหน้ารวมรูปทุกแบบไว้ตรวจด้วยตา ไม่ใช่หน้าที่นักเรียนเห็น

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร | ใครเปิด |
|---|---|---|
| `chem.html` | **ไฟล์ต้นฉบับของครู** — มีเฉลย สถิติชั้นเรียน และการพิมพ์ครบ | ครู |
| `index.html` | **ไฟล์ฉบับแจกนักเรียน** สร้างจาก `chem.html` ด้วย `tools/build-dist.mjs` | นักเรียน |

**ห้ามแก้ `index.html` ตรง ๆ** เพราะจะถูกเขียนทับในรอบถัดไป

## เริ่มใช้งาน

1. เปิด `chem.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย ไม่ต้องต่อเน็ต)
2. แท็บ **สร้างชุดโจทย์** → กดชุดลัด เช่น *ฝึกเร็ว 10 ข้อ* หรือเลือกบทและระดับเอง
3. แท็บ **ทำแบบฝึกหัด** → ตอบทีละข้อ ดูวิธีทำ 7 ขั้นได้ทันทีหลังตอบ
4. แท็บ **พิมพ์ / PDF** → พิมพ์ใบงาน ใบเฉลย หรือหลักฐานการเรียนรู้

## การตรวจสอบก่อนปล่อย

```bash
node tools/build-dist.mjs
```

เปิด `chem.html?selftest=1` จะวนสร้างทุกแม่แบบ 200 ชุดตัวเลข แล้วตรวจว่า

- ทุกแม่แบบสร้างโจทย์ได้ทุก seed ไม่มี `undefined` หรือ `NaN` หลุด
- คำตอบอยู่ในรูปที่กำหนด (จำนวนเต็ม · ทศนิยมไม่เกิน 2 ตำแหน่ง · หรือชนิด `exact`)
- วิธีทำครบ 7 ขั้น (ข้อทฤษฎี 3 ขั้น) ไม่มีขั้นไหนว่าง
- ตัวเลือกปรนัยครบ 4 ไม่ซ้ำ และถูกเพียงตัวเดียว
- ทุกบทมีแม่แบบครบทั้ง 4 ระดับ

> ตัวตรวจใช้ **ขอบเขตคำ** ในการหา `NaN` มิฉะนั้นสูตรอย่าง `NaNO₃` หรือ `NaCl`
> จะถูกฟ้องว่าผิดทั้งที่ถูก — เป็นบั๊กที่เคยเกิดขึ้นจริงตอนเพิ่มบทพันธะเคมี

## สำหรับผู้ดูแลโค้ด

โครงไฟล์เหมือนแอพคณิตทุกประการ เพิ่มบทใหม่ทำสามที่

1. เพิ่มบรรทัดใน `TOPICS` เช่น `{ id: 406, grade: 5, ch: 6, icon: '⚗️', name: '…' }`
   — **ห้ามเปลี่ยน id เดิม** เพราะชุดโจทย์ที่ครูสร้างไว้อ้างถึงอยู่
2. เพิ่มบล็อก `T({ topic: 406, … })` และ `TQ({ … })` ให้ครบทั้ง 4 ระดับ
3. เติมสูตรของบทนั้นใน `FORMULAS` โดยใช้ id เดียวกันเป็นคีย์

`id` เข้ารหัสภาคเรียนไว้ในตัว: `4xx` = เทอม 1 · `5xx` = เทอม 2 · `9xx` = หมวดพิเศษ

**ข้อควรระวังของช่องในใบสรุปสูตร** — ช่อง `e` ผ่านตัวเรนเดอร์คณิต จึงเขียน `frac(a,b)`
และ `H_2O` ได้ และใส่แท็ก `<b>` ได้ · ส่วนช่อง `d` เป็น HTML ธรรมดา
ต้องเขียนสัญลักษณ์ตรง ๆ เช่น `½` `√2` `r²` แทน
